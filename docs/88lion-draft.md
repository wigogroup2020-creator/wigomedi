# 88LION 홈페이지 1차 초안

현재 도메인과 기존 파란색·전체화면 구성은 유지한다. 첨부 작업지시서의 문구를 기준으로 하고, 첨부 HTML에서 남아 있던 뉴벡스·리바이브셀 메뉴·주사 장면은 메인에서 제외했다. 브랜드 로고는 88LION SVG 워드마크(기본색·흰색)로 헤더·전체 메뉴·푸터에 통일했다. 첨부 자료의 사자 심볼은 별도 원본이 없어 임의로 재현하지 않았다. 88LION 프로그램 이미지는 제공된 HTML에서 추출한 원본이며, 새 효능·모델·수치·가격은 작성하지 않았다.

## 적용한 화면

- 공통 로고, PC·모바일 전체 메뉴, 푸터, 페이지별 title/description, canonical, OG/Twitter 카드, 공유 이미지와 파비콘.
- 메뉴: ABOUT US · PRODUCT〔88LION / ALLVIS〕 · STORES · CONTACT · CUSTOMER.
- 메인 슬라이드·기업소개·제품 카드 2종·파트너 문의·자료 링크·마지막 화면 문구.
- 회사소개 및 88LION/ALLVIS 소개 화면. 기존 제품 상세·주문·관리자 제품 데이터는 보존하며 새 소개 화면에서 옛 제품을 노출하지 않는다. 세부 모델·가격은 최신 제품자료 확인 후 별도 반영한다.
- 문의 안내·유형·버튼 문구. 기존 `m41_update.php` 저장·수신 처리는 변경하지 않았다. 이번 검증에서 운영 문의 접수를 전송하지 않았다.
- 자료실은 기존 ALLVIS 카탈로그를 연결하고, DB 자료는 88LION/ALLVIS 제목인 항목만 노출한다. 공지 목록은 뉴벡스·리바이브셀 제목의 항목을 제외한다. 원본 파일·DB 자료·과거 상세 주소는 삭제하거나 일괄 리다이렉트하지 않는다.

## 매장안내 관리

- 공개 화면: `/pages/stores.html`. 검색·지도 API·상세 페이지 없이 매장 사진·매장명·간단한 위치·네이버 지도 링크를 카드로 표시한다. PC 3열, 태블릿 2열, 모바일 1열.
- 관리자: 기존 회원관리 메뉴의 **매장안내 관리** → `/adm/stores.php`.
- 최고관리자가 최초 1회 **매장 관리 초기 설정**을 누르면 현재 `G5_TABLE_PREFIX`의 `stores` 테이블만 생성한다. DB 계정에 CREATE 권한이 필요하며 기존 회원·제품·문의 테이블은 변경하지 않는다.
- 추가·수정·삭제, 사진 미리보기·교체, 공개/숨김, 노출 순서(작은 숫자 우선)를 지원한다. 기본은 숨김이며 실제 방문 가능한 매장만 등록한다.
- 추가 관리자에게는 기존 관리권한설정에서 메뉴 코드 `100305`의 읽기/쓰기/삭제 권한을 부여한다. 모든 변경은 관리자 권한과 기존 CSRF 토큰을 확인한 POST 요청으로 처리한다.
- 사진은 `data/stores`에 임의 파일명으로 저장한다. PHP GD가 필요하며 JPG·PNG·WEBP를 검사 후 JPG로 재인코딩하고 긴 변을 최대 1600px로 저장한다. 코드 제한은 5MB·가로세로 6000px·1600만 화소이며 PHP `upload_max_filesize`, `post_max_size`가 더 작으면 서버 한도가 우선한다. 서버 프로세스의 해당 폴더 쓰기 권한이 필요하다.
- 네이버 HTTPS 지도/플레이스 공유 주소만 허용한다. 지도 API 키는 필요하지 않다.
- 실제 매장 자료는 제공되지 않았다. 테스트 자료는 검증 후 삭제했으며, 등록 매장이 없으면 준비 중 안내와 기존 대표번호를 표시한다.

## 검증

- 메인·회사소개·88LION·ALLVIS·STORES·문의·공지·자료실 8개 화면 HTTP 200 및 페이지별 제목 확인.
- Chromium 1440px/390px에서 화면·모바일 전체 메뉴·가로 넘침 점검. 제품 카드 2개, STORES 메뉴, 클라이언트 JS 오류 없음 확인.
- 별도 로컬 DB의 임시 관리자 계정으로 테이블 초기화, 사진 업로드, 숨김·공개, 정렬, 문구·사진 교체, 삭제, 빈 목록을 검증. 잘못된 CSRF 토큰·비로그인 변경 요청·네이버 사칭 URL·가짜 이미지 업로드 차단 확인. 임시 계정·매장·사진은 정리.
- 변경 PHP/HTML 문법 검사, JS 문법 검사, `git diff --check` 통과.

## 후속 작업

운영 서버 업로드/DB 초기화, 실제 매장·제품자료 등록, 운영 문의 저장/수신 확인은 배포 단계에서 진행한다. 기존 회사명·설립연도·사업자정보·대표번호·이메일·주소·SNS 링크·카카오채널 주소는 유지했다. SNS·카카오 계정의 이름·이미지 변경, 검색엔진 수집 요청은 외부 관리자 작업이다. 신규 도메인·301 이전은 주소 확정 후 진행한다. 영문 `/en/` 소스는 이 저장소에 없어 번역 페이지 작업은 포함하지 않았다. 개인정보처리방침·회원/주문 기능 개편은 하지 않았다.

메인·회사소개 추가 정리: 작업지시서의 슬라이드 3종, 기업소개 요약, 회사 개요·주요 사업영역·비전 문구를 대조했다. 헤더·전체 메뉴·푸터·공유 이미지의 워드마크를 통일하고, 공통 CSS의 옛 로고·옛 제품 배경 참조도 정리했다. 회사명·설립연도·사업자정보·연락처·현재 도메인은 유지한다.
